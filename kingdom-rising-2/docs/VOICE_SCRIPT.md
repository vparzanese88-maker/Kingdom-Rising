# Kingdom Arena voice script

## How to record
- Use a quiet room with a phone held about 20 cm (one hand-width) from your mouth. Blankets or a closet stop the echo.
- Say each line **3 times**: calm, normal and big. I'll pick the best take.
- Leave a 2-second gap between lines. One file per class is fine: `ranger.m4a`, `necro.m4a` and so on.
- Act it. Overdo it a little; game voices are bigger than real speech.
- Grunts count too. At the end of each class, record 3 pain grunts, 2 attack yells and 1 death cry.

## What I do to your voice
I process every file with pitch and formant shifting (that changes the size of the voice, not just how high it is), EQ, distortion, reverb, echo and layering. One person can sound like 20 different characters.

| Effect | Used for |
|---|---|
| Deep giant: pitch down 3–5, formants down | Berserker, Shadow Knight, Beastmaster |
| Demon double: your voice plus a copy an octave down, with grit | Necro, Shadow Knight's ultimate |
| Hollow undead: a little lower, metallic ring, whisper layer | Necro |
| Holy: slightly brighter, cathedral reverb, soft choir double | Paladin, Cleric, Priest |
| Ethereal: higher formants, shimmer and echo | Enchanter, Druid, Wood-Elf types |
| Goblin: pitch up 4–6, formants up, a little faster | Bombardier |
| Spirit echo: low double, cave reverb | Shaman |
| Clean hero: light compression only | Warrior, Ranger, Musketeer, Monk, Bard |
| Female voices: pitch up 3–4 with formants up | Cleric, Priest, Enchanter, Druid. These work better if a woman reads them; otherwise I'll shift yours. |

Line types: **Pick** = chosen on the select screen. **Ult** = ultimate (shout it). **Kill**, **Death**, **Hurt** = low health. **Ability** = a common call-out. **Taunt**. **Win**.

### Warrior: steady veteran knight, confident and loud
Read it like a captain leading a charge.
- Pick: "Shield up. Blade ready. Let's finish this."
- Ult: "STAND AND FIGHT!"
- Kill: "Yield next time." / "One less."
- Death: "Not… yet…"
- Hurt: "I need a hand here!"
- Ability: "Hold the line!"
- Taunt: "Is that all Aldermere has left?"
- Win: "The field is ours!"
